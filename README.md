# 💰 Personal Finance Manager

A beginner-friendly **Command-Line Personal Finance Management System** built using **Python** and **SQLite**. This application helps users securely manage their personal income and expenses with authentication, transaction management, and financial reports.

---

## 🚀 Features

- 🔐 User Registration
- 🔑 User Login
- 🔒 Secure Password Hashing
- ➕ Add Income & Expense Transactions
- 📋 View All Transactions
- 🔍 Search Transactions by Category
- ✏️ Update Existing Transactions
- 🗑️ Delete Transactions
- 📊 Balance Summary
- 📈 Category-wise Expense Report
- ✅ Input Validation
- 🗄️ SQLite Database Integration
- 📂 Modular Python Project Structure

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/chaithanya1486/Personal-Finance-Manager.git
```

2. Navigate to the project folder

```bash
cd Personal-Finance-Manager
```

3. Run the application

```bash
python main.py
```
