# 💰 Personal Finance Manager

A beginner-friendly command-line Personal Finance Management System built using Python and SQLite.

## 🚀 Features

- User Registration
- User Login
- Password Hashing
- SQLite Database
- Modular Project Structure

## 🛠️ Technologies Used

- Python
- SQLite
- hashlib
