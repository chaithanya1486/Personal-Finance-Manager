# 💰 Personal Finance Manager

A beginner-friendly **Command-Line Personal Finance Management System** built using **Python** and **SQLite**. This project allows users to securely manage their personal finances by recording, viewing, updating, searching, and deleting transactions through a simple CLI interface.

---

## 🚀 Features

### 👤 User Management
- User Registration
- Secure User Login
- Password Hashing for Security

### 💳 Transaction Management
- Add Transaction
- View Transactions
- Search Transactions
- Update Transactions
- Delete Transactions

### 🗄️ Database
- SQLite Database Integration
- User-specific Transaction Storage
- Parameterized SQL Queries
